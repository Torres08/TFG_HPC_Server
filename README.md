# TFG

Este repositorio contiene los materiales y recursos relacionados con mi Trabajo de Fin de Grado (TFG).

## Estructura de carpetas

- **benchmark/**  
  Scripts, archivos de configuración y logs para pruebas de rendimiento, incluyendo archivos de Apache JMeter, resultados (`summary.csv`, etc.) y subcarpetas con datos de pruebas.

- **Clokify/**  
  Informes de seguimiento de tiempo y planificación, incluyendo reportes exportados de Clockify, diagramas de Gantt y recursos de gestión temporal.

- **Documento/**  
  Documentación principal del TFG en formato LaTeX, incluyendo el archivo principal (`proyecto.tex`), capítulos, bibliografía, glosario, imágenes y anexos.

- **Entrega/**  
  Carpeta destinada a la entrega final del TFG, versiones listas para evaluación o presentación.

- **Slidev/**  
  Presentación de diapositivas del TFG, creada con Slidev. Incluye los archivos fuente (`slides.md`), imágenes y capítulos en formato LaTeX para la presentación.

- **tokenizer/**  
  Scripts y utilidades para el conteo de tokens en prompts de modelos de lenguaje, junto con documentación específica.
