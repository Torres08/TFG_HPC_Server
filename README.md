# TFG

Este repositorio contiene los materiales y recursos relacionados con el Trabajo de Fin de Grado (TFG).

## Estructura de carpetas

- **Benchmark/**  
  Scripts, archivos de configuración y logs para pruebas de rendimiento, incluyendo archivos de Apache JMeter y resultados de benchmarks.

- **Documento/**  
  Documentación principal del TFG en formato LaTeX, incluyendo el archivo principal (`proyecto.tex`), bibliografía, glosario, imágenes y capítulos del documento.

---

Cada carpeta está organizada para facilitar el acceso y la gestión de los diferentes componentes del proyecto.
